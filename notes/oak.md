# OAK

**What it is**
Ontology Access Kit (OAK) is documented as a toolkit for working with ontologies through both Python and a command line. Its documentation spans ontology access, transformation, validation, graph operations, mappings, similarity, and multiple ontology-related data models.

**Key concepts**
CURIEs and URIs; labels, aliases, and synonyms; mappings and cross-references; relationships and graphs; adapters and triplestore backends; OboGraphs, OWL, SSSOM, KGCL, and semantic similarity.

**How you'd use it**
Follow the Python or command-line tutorials, choose an ontology adapter/backend, then use the relevant interface, converter, utility, or how-to guide for tasks such as graph visualization, validation, applying ontology changes, similarity analysis, or cross-ontology diffing.
